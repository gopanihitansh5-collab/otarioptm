# Demo Storytelling

Own the narrative: docs/demo-script.md talk track, landing story
consistency, and presenter notes. The story arc is problem -> intelligence
-> live demo -> evidence -> honest roadmap. Every spoken claim must map to
a verified capability in docs/product-capabilities.md; planned features are
named as planned, on stage and in writing. Keep the ~10 minute timing and
the reset checklist in docs/demo-runbook.md accurate.
